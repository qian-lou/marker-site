再多了解一点

你可能想知道。

Marker 是阅读器，还是编辑器？+

两者都是。你可以沉浸阅读本地 Markdown 文档，也可以使用所见即所得编辑，或在源码与预览分栏中写作。阅读、编辑和源码模式切换时会保留当前草稿。

需要注册账号或保持联网吗？+

不需要注册账号。日常文档读写在本地完成，离线也能使用。文档中的外部链接和远程图片需要网络；远程图片默认关闭，可按需开启。

文档会保存在哪里？+

文档以 Markdown 文件保存在你自己的电脑中。你可以打开已有文件或文件夹，编辑后保存到本地，也可以用其他兼容 Markdown 的工具继续使用这些文件。

这里可以直接编辑我的文件吗？+

这里是 Marker 官网，页面中的工作台是交互示意，你可以切换示例文档、源码视图与阅读配色。完整的本地文件读写功能在 Marker 桌面应用中使用。
