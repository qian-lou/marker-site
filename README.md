# Marker

**简体中文** · [English](./README.en.md)

> 把专注，还给文字。

Marker 是一款本地优先的 Markdown 阅读与编辑工具，面向 macOS、Windows 和 Linux。你可以沉浸阅读本地文档，用所见即所得的方式写作，或在源码与实时预览之间打磨内容。无需账号，日常读写离线可用，文档以标准 Markdown 文件保存在自己的电脑中。

[访问官网](https://qian-lou.github.io/marker-site/) · [在线体验](https://qian-lou.github.io/marker-site/#experience) · [下载安装包](https://github.com/qian-lou/marker-site/releases) · [问题反馈](https://github.com/qian-lou/marker-site/issues/new?template=bug_report.yml) · [功能建议](https://github.com/qian-lou/marker-site/issues/new?template=feature_request.yml)

## 阅读、写作，在同一处完成

无论是阅读项目 README、整理会议笔记，还是编写带代码与图表的技术文档，都可以从打开一份 Markdown 文件开始。

| 模式 | 使用方式 |
| --- | --- |
| 只读 | 专注于排版后的正文，通过大纲跳转章节，用文内搜索定位内容。 |
| 编辑 | 直接修改排版后的文字，使用选区格式工具和插入菜单组织内容。 |
| 源码 | 编辑 Markdown 源码，在分栏中实时查看预览。 |

三种模式切换时保留当前草稿，可以按照自己的习惯在阅读和写作之间转换。

## 核心功能

- **无限画板**：用便签、画框、卡片、文本、智能连线和手绘组织想法。支持模板、多选对齐、图层排序、元素右键操作与独立撤销重做；保存为 canvas JSON 代码块，阅读与导出沿用矢量图。
- **表格编辑与布局**：通过边缘按钮、右键或 Shift+F10 菜单增删行列、选择与清空内容，拖动或用方向键调整列宽和行高，双击恢复自动尺寸。布局随 Markdown 注释保存，阅读和导出沿用，支持撤销重做。
- **共享字体选项**：中文、英文与代码可选择 Menlo、Monaco、Inconsolata 和 Space Grotesk；代码预览使用所选字体，未安装时按字体栈回退。
- **可视化流程图**：在画布上插入、拖动与缩放流程符号，双击改字，连接或换接节点，调整连线走线、箭头与文字；支持多选、对齐、分布、样式设置和撤销重做。完成后写回 Mermaid，布局与样式随注释保存；高级语法可继续使用源码与实时预览。
- **图表高度记忆**：拖动编辑预览底边或用方向键调高，阅读模式沿用同一高度并自适应显示，桌面版重启可恢复；阅读与编辑使用一致的紧凑顶部间距。
- **公式工作台与片段库**：就地编辑或展开专注工作台，使用 LaTeX 高亮、命令补全、参数跳转与独立撤销重做；常用公式可按分类、标签和置顶整理，支持 JSON 导入导出。桌面版还会恢复未确认的公式草稿与工作台布局。
- **交互 HTML 与 JavaScript**：手动运行 JavaScript，查看页面、点击交互与控制台输出；HTML 预览支持内嵌脚本、事件、CDN 资源和动态高度。网页请求遵循浏览器 CORS；桌面版提供本地代理。代码在独立沙箱中运行，不会自动执行。
- **文件树右键操作**：打开到侧边、固定标签、复制名称或路径、刷新及折叠目录；桌面版可在已授权工作区新建、重命名、复制与删除条目。默认浅色外观采用柔和暖白色调。
- **正文右键插入与可选状态栏**：在编辑正文中右键打开可搜索的插入菜单，支持方向键、Enter 和 Esc；在设置 → 外观中切换底部状态栏显隐，桌面版也可通过视图菜单切换。
- **图片编辑与一致布局**：调整说明、缩放和图片区域尺寸，拖动边缘或角落改变区域；阅读、预览和导出保持完整图片比例，分页导出避免将整张图片拆到不同页面。
- **草稿与编辑恢复**：切换文档保留各自草稿、正文与源码的撤销重做、光标、选区和滚动位置；桌面版重启可恢复未保存和未命名文档，状态栏显示更改保护状态，已落盘的恢复日志用于异常退出后的恢复。
- **清晰的文档工作台**：文件树、正文与大纲分栏呈现；顶部打开、搜索与文件树按钮跟随左侧栏宽度对齐，展开、收起平滑过渡，拖动分隔线时同步跟随。可用方向键调整宽度，双击恢复默认；系统减少动态效果设置下关闭过渡。
- **本地文件与多文件夹工作区**：打开已有文件或文件夹，浏览多层目录；独立文件与工作区文档可以保留在同一侧栏，点击切换。
- **快速查找文件**：顶部搜索按钮或 ⌘/Ctrl+P 打开搜索弹窗，按文件名或路径查找；支持树形 / 列表切换、目录展开折叠及键盘打开，切换视图保留搜索词和选中文件。
- **多文档标签页**：切换、拖动和固定已打开的标签；右键可关闭其他标签或重新打开关闭的文档，标签列表支持按文件名或路径搜索与键盘切换。
- **离线导出**：将当前草稿导出为 PDF、HTML、PNG、Word、OpenOffice、RTF、EPUB、LaTeX、MediaWiki、reStructuredText、Textile 或 OPML。桌面版内置转换能力，无需额外安装；可调整纸张、方向、页边距、字号和图片倍率。
- **Windows 原生菜单**：通过文件、编辑、视图和帮助菜单完成常用操作；macOS 使用系统菜单栏。
- **按工作区整理文件**：移除工作区会同步清理其打开过的文件记录，桌面版重启后不再恢复；未保存内容会先提示，其他工作区和独立文件保持不变。
- **接着上次读**：悬停顶部文件名可关闭当前文档，文件仍保留在侧栏；再次打开或切换回来会恢复各自的阅读位置。桌面版重启后还会恢复文件列表、当前文件与各级目录的展开、折叠状态。
- **更紧凑的写作界面**：插入、撤销和重做集中在顶部，正文直接开始；插入菜单支持输入过滤，深色弹窗使用统一的深灰按钮。
- **选区格式与块拖动**：选中文字调整段落、加粗、下划线、文字颜色与高亮，支持自定义颜色和最近使用颜色。拖动段落左侧把手调整同级块顺序，使用撤销与重做回顾修改。
- **记住分屏比例**：拖动源码与预览之间的分隔线，方向键微调，双击恢复均分；切换模式或重新打开后恢复，窄窗口只临时适配显示宽度。
- **适合技术文档的表达能力**：支持代码高亮与折叠、GFM 表格、任务清单、数学公式和 Mermaid 图表。
- **按习惯调整阅读体验**：提供 12 款阅读皮肤、浅色与深色外观，以及字体、字号、行高和正文宽度设置。字号按 0.1px、行距按 0.01 微调，滑块与数字输入实时联动，点击数值即可全选替换。
- **按需显示顶部工具栏**：在设置中选择常驻或自动隐藏；鼠标移到窗口顶部即可唤出，移开 1 秒后收起，返回时取消隐藏，正文不会跳动。桌面版会在重启和升级后保留设置。
- **中文与英文界面**：在熟悉的语言中阅读、写作和调整设置。
- **文件由你掌握**：无需注册，日常读写在本地完成；使用标准 Markdown 格式，便于继续用其他兼容工具处理。远程图片默认关闭，可按需开启。

## 下载与开始使用

前往 [下载页面](https://github.com/qian-lou/marker-site/releases)，选择适合自己系统与处理器架构的安装包。

| 系统 | 架构 | 安装格式 |
| --- | --- | --- |
| macOS 15+ | Apple Silicon / ARM64、Intel / x64 | `.dmg` |
| Windows | x64 | `.exe` |
| Linux | x64 | `.deb`、`.AppImage` |

1. 安装并打开 Marker，无需创建账号。
2. 打开本地 Markdown 文件，或添加文件夹作为工作区。
3. 使用大纲与搜索阅读内容，切换到「编辑」或「源码」修改文档，再保存到本地。

桌面应用支持应用内更新，有新版本时会显示更新提示，由你确认后下载并安装。文档中的外部链接、远程图片以及应用更新需要联网。

## 先在浏览器里体验

[官网产品体验区](https://qian-lou.github.io/marker-site/#experience) 直接运行 Marker 的真实前端界面，可以通过图标切换阅读、编辑与源码模式，体验文件树、文件切换、大纲和阅读设置。

- 打开 `Markdown.md` 的「在无限画板中整理想法」，切到编辑并点击画板顶部的「可视化编辑」；试试模板、右键复制或改字，再完成并切到只读或导出 HTML。
- 打开 `Markdown.md`，查看代码、表格、数学公式与 Mermaid 图表。
- 点击顶部文件树按钮，观察侧栏与顶部控件同步收放；拖动分隔线、用方向键微调或双击恢复默认宽度。
- 在编辑模式使用表格边缘的 ＋ / −，右键或 Shift+F10 打开表格菜单；调整列宽与行高，再切到只读或导出 HTML 检查布局。在设置中选择正文与代码字体，查看实时预览。
- 切到编辑，在图表顶部打开「可视化编辑」；拖动图形、双击改字，试试多选对齐和连线调整。点击「完成」，切回只读查看结果，再返回编辑撤销正文修改；拖动预览底边并切换模式，检查共享高度。
- 切到编辑并点击公式，展开专注工作台，试试命令补全、参数跳转、撤销重做和错误定位；保存自定义公式，在「我的公式」中按分类或标签筛选、置顶，再通过 JSON 导出或导入备份。
- 点击 JavaScript 代码块顶部「运行 JavaScript」，点击结果中的按钮并查看日志；停止运行后保留画面。点击 HTML 代码块的「渲染 HTML」，添加灵感并观察高度随内容变化，再切回「查看源码」。
- 右键示例文件或目录，试试打开到侧边、固定、复制路径和刷新；网页禁用磁盘修改操作。
- 在编辑正文中右键，输入「表格」过滤插入菜单；用方向键与 Enter 插入，Esc 返回正文。在设置 → 外观中关闭或打开「显示状态栏」。
- 在图片示例上调整说明、缩放和区域尺寸，切到只读或源码检查布局；图片支持撤销与重做，并沿用到浏览器导出。
- 修改文档后切换到其他标签再回来，继续草稿、光标与各模式的撤销重做；未保存状态持续显示。网页记录仅限当前页面，刷新或重置后清空，重启与崩溃恢复请使用桌面版。
- 点击图表标题折叠或展开整块图表；切换文件或模式后保留状态，刷新或重置体验后清空。界面同步更柔和的深色选区与细分隔线。
- 切到编辑模式，体验代码块顶部的单行工具栏、任务勾选和表格编辑；再切回只读或源码模式，当前草稿继续保留。
- 选中文字，试试浮动工具栏中的段落格式、下划线、文字颜色与高亮；输入自定义十六进制颜色，再重新打开面板使用最近颜色。按 Alt+F10 进入工具栏，Esc 返回正文。
- 在只读、编辑、源码和代码块中体验统一圆角选区；切换浅色与深色，查看正文、引用和表格的对比度。
- 拖动段落左侧的六点把手调整同级内容顺序，再撤销或重做；切回只读或源码查看格式与草稿。
- 点击顶部「插入」，输入「表格」或「公式」过滤并插入内容；正文输入 `/` 也可以打开紧凑菜单。
- 切到源码模式，左右拖动中间分隔线，再切换模式或刷新页面；分屏比例会保存在当前浏览器中。
- 使用图表的 ＋ / − 连续缩放，放大后横向滚动查看内容；点击百分比重置，或打开弹窗查看大图。
- 图表弹窗自动适配画布和窗口变化，支持拖动平移、滚轮缩放与复制源码；点击「适应窗口」、双击画布或按 0 恢复完整视图，按 Esc 关闭。
- 展开 `Projects → Marker → Release`，体验多层目录导航；打开 `Quick note.md`，体验独立文件的切换、搜索与移除。
- 点击「搜索示例文件」，输入 `Checklist`，在树形与列表之间切换并打开深层目录中的文件；也可搜索 `Quick note` 打开独立文件。
- 打开多份文档，切换顶部标签，右键固定常用文档，再通过标签列表搜索已打开的文件。
- 标签列表补全所属工作区路径，只有文件名时省略重复副标题；新建标签和插入内容使用不同图标。
- 点击顶部「导出」，下载 PDF、HTML 或 PNG，或调整导出设置。Word、EPUB 等其他格式请使用桌面版。
- 导出菜单在按钮下方展开并适配窗口边界；操作结果使用轻量彩色提示条，自动消失，悬停或聚焦时暂停，可手动关闭。
- 悬停顶部文件名并点击 `×` 关闭文档，从侧栏或最近文件重新打开，继续之前的阅读位置。
- 打开设置，拖动滑块，或点击数值全选后输入字号、行距，观察正文实时变化。
- 修改示例文档或切换阅读皮肤，也可以主动选择本地文件在浏览器中体验，文件不会上传。

文档与未确认的公式修改仅保留在当前页面，刷新页面或点击「重置体验」可还原；公式片段、最近使用、收藏、工作台布局与最近颜色保存在当前浏览器中，重置示例会保留公式库。完整的磁盘保存、重启恢复和应用内更新请使用桌面应用。
