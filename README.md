## 设计理念：阅读与写作，在同一处自然流转

无论是研读开源项目 `README`、整理会议纪要，还是编写包含复杂代码、数学公式与架构图表的技术文档，Marker 都让你从直接打开一份本地 Markdown 文件开始。

| 工作模式 | 核心定位 | 交互体验 |
| :--- | :--- | :--- |
| **只读模式 (Read)** | 沉浸式深度阅读 | 专注于排版后的正文，通过右侧层级大纲快速跳转章节，配合文内搜索精准定位内容。 |
| **编辑模式 (Edit)** | 所见即所得创作 | 直接在排版视图中落笔，通过 `/` 斜杠命令、右键菜单、浮动格式栏与可视化工作台组织内容。 |
| **源码模式 (Source)** | 精确语法控制 | 左栏编辑标准 Markdown 源码，右栏实时同步渲染预览；支持自由拖拽分屏比例并持久记忆。 |

> **零损耗模式切换**：在「只读 / 编辑 / 源码」三种模式间切换，或在多个文档标签页之间跳转时，Marker 会完整保留各文档当前的未保存草稿、模式独立的撤销/重做历史、光标位置、选区及滚动进度。

## 核心功能体系

### 1. 沉浸阅读与精细排版

- **12 款阅读皮肤与深浅外观**：默认浅色外观采用柔和暖白纸感色调，强化正文、引用与表格对比度；深色模式提供静谧柔和的选区高亮与统一深灰控件。只读、编辑、源码与代码块共享一致的圆角文字选区。
- **内容与界面字体解耦**：在「设置 → 外观 → 字体设置」中，可为文档内容（正文、标题、代码）与工作台界面（文件树、大纲、工具栏、设置）独立配置中英文字体；共享 `Menlo`、`Monaco`、`Inconsolata` 与 `Space Grotesk` 等经典字体选项，并提供实时预览与系统字体栈回退。
- **像素级排版参数微调**：支持调节正文版心宽度；字号支持按 `0.1px` 步进、行距支持按 `0.01` 步进微调，滑块与数字输入框实时联动（点击数值自动全选以便快速替换）。
- **无干扰自适应界面**：顶部工具栏支持「常驻」或「自动隐藏」（鼠标移至窗口顶部唤出，离开 1 秒后平滑收起，期间返回自动取消隐藏，正文布局零跳动）；底部状态栏可通过设置或桌面视图菜单按需显隐。

### 2. 所见即所得写作与结构化编排

- **可搜索插入菜单与块拖拽**：在编辑正文中输入 `/` 或点击鼠标右键，即可呼出单列可搜索插入菜单，支持中文、英文、拼音及常用别名（如 `todo`、`warning`、`zhedie`）过滤；拖动段落左侧的六点把手即可重排同级内容块顺序。
- **选区格式与自定义色彩**：选中文字后通过浮动工具栏快速调整段落层级、加粗、下划线、选中文字字号、文字颜色与背景高亮；支持输入自定义十六进制颜色并记忆最近使用颜色，支持 `Alt+F10` 键盘聚焦工具栏。
- **语义提示块与嵌套折叠块**：直接编辑标题与正文，一键切换 4 种提示块类型（`[!NOTE]` 等）或创建可嵌套折叠块（`<details>`）；在块内插入新内容自动继承当前提示或折叠层级，阅读模式保留交互样式，文档导出时自动展开全部正文。
- **表格与图片可视化布局**：
  - **表格编辑**：通过表格边缘 `＋ / −` 按钮、右键或 `Shift+F10` 菜单快捷增删行列、选中整行/整列或清空单元格；拖动分隔线或用方向键调整列宽与行高，双击恢复自动尺寸。
  - **图片与多图块混排**：调整图片说明文字、缩放比例与区域尺寸；支持拖拽可视图块右边或底边调整尺寸，实现图文并排或双图并排（窄窗口下自动上下堆叠）。
  - **安全块删除与无损持久化**：单击可视图块预览可选中整块，在相邻段落边界按 `Backspace` / `Delete` 采用「先选中、再删除」两段式防误删设计；所有表格、图片与图块布局元数据均通过 Markdown 注释保存，阅读与导出保持一致比例。

### 3. 五大可视化创作工作台

- **数据图表工作台 (`chart`)**：直接编辑内置表格，或粘贴 Excel / WPS 制表符（TSV）、CSV、Markdown 表格数据，实时切换**柱状图、折线图与饼图**；支持调整标题、单位、随皮肤自适应的配色方案、图例与数值标签。严格保留空值缺失语义与数据格式校验，支持独立撤销重做，阅读与导出沿用同一离线矢量渲染。
- **思维导图工作台 (`mindmap`)**：在「导图画布、层级大纲、Mermaid 源码」三种视图间自由切换；支持增删改主题、拖拽重组分支、3 种布局方向（双向、右向、向下）与 8 款主题皮肤，配备整理动画、节点搜索、分支折叠与缩略图导航。修改写回标准 Mermaid `mindmap` 语法，支持一键复制图片或独立导出 SVG / PNG。
- **可视化流程图编辑器 (`mermaid`)**：内置 26 类标准流程符号，在画布上直接插入、拖拽、八方向缩放与双击改字；支持连接点吸附、端点换接、折线/曲线路由调整、框选多选、对齐与等距分布、标尺网格及独立撤销重做。布局与样式随 Mermaid 注释保存；含高级语法的图表自动保留源码编辑与实时预览，不做有损转换。图表块支持整体折叠、预览区高度拖拽记忆，以及独立弹窗大图浏览（支持平移、滚轮缩放、`0` 键或双击适应窗口）。
- **无限画板 (`canvas`)**：用便签、画框、卡片、文本、智能连线与自由手绘整理架构与灵感；内置头脑风暴、架构蓝图与敏捷看板模板，支持多选对齐、图层排序与右键快捷操作，以 `canvas` JSON 代码块保存并支持矢量渲染导出。
- **LaTeX 公式工作台与片段库**：支持行内就地编辑或展开专注工作台，提供 LaTeX 语法高亮、命令补全、参数跳转、错误定位与独立撤销重做；常用公式可在「我的公式」中按分类、标签和置顶整理，支持 JSON 导入导出备份，桌面端重启可恢复未确认的公式草稿与工作台布局。

### 4. 交互式代码沙箱与技术文档增强

- **JavaScript 独立沙箱**：在阅读或编辑模式下手动点击「运行 JavaScript」，在隔离沙箱中执行 DOM 操作、点击交互、Canvas 绘制与控制台输出；页面高度随内容动态伸缩，停止运行后保留当前画面，绝不自动执行未知代码。
- **HTML 实时渲染预览**：原位切换源码与交互预览，支持内嵌脚本、事件绑定、外部 CDN 资源加载与动态高度适配；网页端遵循浏览器 CORS，桌面端内置独立令牌的本地代理转发。
- **开发者友好代码块**：支持多语言语法高亮、代码块折叠、单行紧凑工具栏、聚焦当前代码行高亮、源码区底边高度拖拽记忆，以及交互式终端命令模拟。

### 5. 多工作区管理与毫秒级检索

- **三栏工作台与多文档分栏**：文件树、正文与大纲分栏呈现，顶部按钮区与左侧栏宽度实时同步对齐（支持拖拽分隔线、方向键微调、双击恢复默认宽度，并遵循系统减少动态效果设置）。拖动文档标签至编辑区边缘即可组合多文档分栏视图。
- **多文件夹工作区与标签页**：支持同时挂载多个本地文件夹工作区与独立 Markdown 文件；标签栏支持拖拽排序、固定常用标签、右键关闭其他/重新打开已关闭标签，以及含工作区路径的标签列表搜索。关闭独立文件标签后仍保留在侧栏，重新打开自动恢复上次阅读位置。
- **文件树右键管理**：支持打开到侧边分栏、固定标签、复制文件名或路径、刷新及折叠目录；桌面版可在已授权工作区中直接新建、重命名、复制与删除文件或文件夹。
- **快速查找文件 (`⌘/Ctrl+P`)**：按文件名、路径、多词组合或有序字符缩写毫秒级检索文件，文件名匹配优先排序，支持树形与列表视图无缝切换。
- **跨文档全文搜索 (`⌘/Ctrl+Shift+F`)**：支持检索全部工作区、指定工作区或已打开文档（含未保存草稿），提供大小写匹配、上下文高亮片段与行列号预览，按 `Enter` 直达源码并选中匹配项。桌面端复用仅存路径哈希、文件指纹与 Bloom 位图的本地增量索引，兼顾速度与隐私。

### 6. 全格式离线导出与本地数据安全

- **12+ 种格式离线导出**：桌面版内置完整文档转换引擎（无需额外安装外部依赖），可将当前草稿直接导出为 **PDF、HTML、PNG、Word (DOCX)、OpenOffice (ODT)、RTF、EPUB、LaTeX、MediaWiki、reStructuredText、Textile 或 OPML**；支持自定义纸张规格、页面方向、页边距、字号与图片倍率，分页导出自动保护整张图片不被截断。
- **崩溃保护与会话恢复**：桌面端实时将编辑草稿提交至本地恢复日志，状态栏直观显示更改保护状态；重启应用或异常退出后，可完整恢复未保存文档、未命名草稿、工作区目录展开状态、分屏比例与阅读位置。移除工作区时自动清理关联记录，并在存在未保存修改时先行提示。
- **纯粹本地优先**：无需注册登录，所有文档均为保存在本地磁盘的标准 Markdown 文件，可随时与 Git 或任何兼容工具配合使用；远程图片默认拦截，可按需开启。

## 下载与快速开始

前往 [GitHub Releases 下载页面](https://github.com/qian-lou/marker-site/releases)，选择对应操作系统与处理器架构的安装包：

| 操作系统 | 处理器架构 | 安装包格式 | 平台原生集成 |
| :--- | :--- | :--- | :--- |
| **macOS 15+** | Apple Silicon (`arm64`) / Intel (`x64`) | `.dmg` | 系统原生菜单栏、窗口与快捷键集成 |
| **Windows** | `x64` | `.exe` | 原生文件、编辑、视图与帮助菜单栏 |
| **Linux** | `x64` | `.deb`、`.AppImage` | 标准桌面环境集成 |

### 三步开始使用

1. **安装并启动**：打开 Marker，无需注册账号或配置复杂环境。
2. **载入文档**：直接打开本地 `.md` 文件，或将本地文件夹添加为工作区。
3. **自由读写与导出**：通过大纲与搜索沉浸阅读，切换至「编辑」或「源码」修改内容，随时保存到本地或通过「文件 → 导出」生成目标格式文档。

> **应用内更新**：桌面版支持签名校验的应用内更新。当检测到新版本时会显示更新提示，由你主动确认后下载并安装。日常读写与导出完全离线可用，仅文档外部链接、远程图片与版本更新检查需要联网。
